Hardware Stack

Do NOT Use Cheap ELM327 V2.1 Clones The cheap Bluetooth ELM327 adapters available in Morocco (80-150 DHS on Avito/AliExpress) are V2.1 clones that only handle CAN protocol reliably. They are incompatible with K-Line/ISO 14230 used by the Kymco ECU. Only genuine ELM327 V1.5+ adapters work, and those are rare and expensive locally. Use the ESP32 stack instead.

System Architecture

The full predictive maintenance pipeline:

1. On-Bike (ESP32)

ESP32 reads live PIDs from ECU via K-Line while riding. Stores data in CSV format on internal flash or SD card. Samples at ~1 Hz.

2. WiFi Sync

When parked at home (in WiFi range), ESP32 uploads CSV logs to GitHub repo via HTTP API. One file per day: /logs/YYYY-MM-DD.csv

3. GitHub Actions

Nightly cron job triggers Python analysis script. Computes durability metrics, detects anomalies, generates JSON report.

4. Dashboard

GitHub Pages static site reads analysis JSON. Displays charts (Chart.js): thermal stress trends, RPM histograms, O2 health, CVT wear curve.

5. Notifications

Critical alerts via ntfy.sh (free push notifications). Warning/info via email from GitHub Actions. Severity-graded: Info → Warning → Critical.

Durability Analysis Rules

Rule 1: Thermal Stress Scoring

Engine temp from NTC sensor. Oil degrades exponentially above 100°C. The script computes a daily thermal stress index:

Temp RangeWear MultiplierAction
80-110 °C1× (normal)No action
110-130 °C2×Monitor — shorten oil change if frequent
130-165 °C5×Warning — check cooling, reduce load
>165 °CCriticalDTC P0217 — stop and investigate

If the weekly thermal stress trend rises consistently → oil change interval should shorten → push notification.

Rule 2: RPM Histogram

Track percentage of riding time in each RPM band. Optimal cruising for durability: 4,000-5,500 RPM. Time spent above 6,500 RPM accelerates valve guide wear (air-cooled + Marrakech heat). Weekly RPM distribution report helps adjust riding habits.

Rule 3: O2 Sensor Drift Detection

7-day rolling average of O2 sensor voltage at idle. Healthy: oscillates 0.2-0.6V. If average drifts consistently above 0.6V (rich) or below 0.2V (lean) → AFR issue → carbon buildup on valves. If O2 voltage becomes static (no oscillation) → sensor dying → replace.

Rule 4: CVT Health via RPM/Speed Ratio

Plot RPM vs speed over time. A healthy CVT has a predictable curve. If RPM-at-max-speed creeps upward over weeks → variator rollers are wearing flat → belt isn't shifting fully. Regression analysis detects this before you feel it.

Rule 5: Idle Stability Scoring

Measure RPM variance at idle (should be 1,700±100 RPM). High variance → carburetor issue, vacuum leak, or valve clearance problem. Correlate with idle solenoid PWM — if PWM climbs toward 90%+ while idle variance increases → pilot jet clogging.

Rule 6: Battery Voltage Trend

Track running voltage over weeks. Healthy: 13.0-14.5V while engine running. If trend drops below 13V progressively → regulator/rectifier degrading → battery will die soon. Predict failure 2-4 weeks before it happens.

Note on Protocol Compatibility The Kymco Agility 50 4T uses the same KWP2000 slow-init protocol as many European scooters and small motorcycles of the 2010-2020 era (Piaggio, Derbi, Aprilia). Code from Honda/Yamaha projects may need adaptation for the specific PID addresses, but the transport layer is identical.
